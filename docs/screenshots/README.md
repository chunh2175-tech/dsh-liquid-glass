# Screenshots

Add a screenshot named `preview.png` here if you want one in the repository.

Recommended framing:

- A **new / empty session** (no chat history).
- Crop to the application window only.
- Blur or omit the sidebar session list, account row, chat text, and any cost widgets.
- Do not upload desktop icons, personal file names, or other people's data.

This project intentionally ships **without** the author's desktop screenshot;
the local verification image contains personal content and is not committed.

The `.gitignore` ignores `docs/screenshots/*.png`, so after review:

```powershell
git add -f docs/screenshots/preview.png
```
